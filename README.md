## ✨ Features & Architecture

- **Multi-Page Routing**: Built with `react-router-dom` with seamless transitions and automatic top scroll.
- **Dedicated Pages**:
  - `/` — **Home Page**: Complete showcase with curated previews of every section and direct lead capture.
  - `/about` — **About Us**: Corporate story, philosophy, 4 core value pillars, and client journey.
  - `/residential` — **Residential Portfolio**: Filterable luxury apartments, villas, and plots in Gurugram with specs and HRERA due diligence checklist.
  - `/commercial` — **Commercial Spaces**: Grade-A office towers, IT parks, retail shops, and tenant representation advisory.
  - `/investment` — **Investment Advisory**: Pre-leased corporate assets with 8-9% annual yields and airport development land parcels.
  - `/locations` — **Location Intelligence**: Interactive city selector highlighting Gurugram operational hub and upcoming national expansion corridors.
  - `/insights` — **Market Perspectives**: Real estate guides, SPR growth reports, and reading modal.
  - `/contact` — **Corporate Contact Desk**: Complete lead capture form, direct phone/WhatsApp/email lines, office details, and advisory FAQs.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/6888mayank/realstate-empire.git

# Navigate into the project folder
cd realstate-empire

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Build & Verification

```bash
# Typecheck
npm run typecheck

# Lint
npm run lint

# Production build
npm run build
```
